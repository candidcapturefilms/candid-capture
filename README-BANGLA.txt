CANDID CAPTURE — WEBSITE FILES
================================

Files included:
- index.html   Website page content
- style.css    Layout, colours, fonts and responsive design
- script.js    Mobile menu, social links and WhatsApp inquiry form

IMPORTANT BEFORE UPLOADING
- These files are a complete static website package.
- The website currently uses sample wedding photos hosted by Unsplash. Replace them with your own photography when ready.
- The WhatsApp inquiry number currently matches the number configured in your existing repository: 8801804358062.
- Facebook is set to https://www.facebook.com/candidcapturefilms
- Instagram is left blank until you provide your actual profile link.

HOW TO UPDATE GITHUB PAGES WITHOUT CODING
1. Open your repository:
   https://github.com/candidcapturefilms/candid-capture
2. Download or keep a backup of the current files before replacing anything.
3. Open the repository's main Code page.
4. Click Add file > Upload files.
5. Extract this ZIP on your computer first.
6. Select index.html, style.css, script.js (and this README if you want) from the extracted folder.
7. GitHub will ask you to commit the changes. At the bottom, choose Commit changes.
8. Wait a few minutes, then refresh:
   https://candidcapturefilms.github.io/candid-capture/

NOTE:
- Do not upload this ZIP file alone and expect GitHub Pages to extract it. Extract it on Windows first, then upload the individual files.
- When GitHub says a file already exists, uploading the file with the same name and committing changes replaces the existing version.
- Do not delete your repository or change its repository name.
- The website needs an internet connection to load Google Fonts and sample photos.
